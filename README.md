Climate System Response and Hysteresis Analysis using CMIP6 Simulations

This project analyzes temperature and precipitation response during CO2 ramp-up and carbon dioxide removal experiments using CMIP6 datasets.

Tools:
- Python
- xarray
- NumPy
- Matplotlib

Main analysis:
- Global mean temperature anomaly
- Precipitation energy response
- Temperature-CO2 hysteresis
- Precipitation-CO2 hysteresis

Dataset:
CNRM-ESM2-1 CMIP6 simulations
